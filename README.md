# To-Do List Management System

A command-line To-Do List Management System developed in Python that demonstrates the practical implementation of multiple data structures and algorithms. The application allows users to create, manage, organize, search, and track tasks efficiently.

## Features

- Add new tasks with deadlines and tags
- Edit existing tasks
- Delete tasks
- Undo deleted tasks
- Mark tasks as completed
- View all tasks in insertion order
- View tasks sorted alphabetically
- Search tasks by tag
- Search tasks by ID using a Hash Table
- Search tasks by title using Binary Search
- View tasks using BFS (Level-Order Traversal)
- Display tasks by earliest deadline
- Manage reminders for upcoming tasks
- Track completed and deleted tasks

## Data Structures Used

### Hash Table (Dictionary)
- Fast task lookup by Task ID
- O(1) average search complexity

### Stack
- Supports Undo functionality for deleted tasks

### Queue (Deque)
- Used for Breadth-First Search (BFS) traversal

### Doubly Linked List
- Stores active tasks
- Supports efficient insertion and deletion

### Binary Search Tree (BST)
- Stores tasks sorted by title
- Supports ordered traversal and searching

### Heap (Priority Queue)
- Organizes tasks by earliest deadline
- Supports reminder management

### Set
- Stores unique task tags

## Algorithms Implemented

- Binary Search
- Breadth-First Search (BFS)
- In-Order BST Traversal
- Heap-based Priority Scheduling
